## Featured Projects

1. **[Trazino — Income & Expense Manager](https://github.com/samira-sadrolashrafi/income-and-expense-manager)**  
   A Persian RTL personal finance application built with PHP, CodeIgniter 3, Bootstrap, JavaScript, and Docker. Features include income and expense tracking, category management, current balance and debt tracking, searchable and filterable transaction lists, pagination, temporary deletion and restoration, and a financial dashboard with cash-flow charts.

2. **[JobPortal — Recruitment Platform](https://github.com/samira-sadrolashrafi/recruitment-platform)**  
   A Django and PostgreSQL platform for job seekers and employers. It supports job posting and search, resume management, applications and status tracking, interview scheduling, notifications, and keyword-based job recommendations.

3. **[Note Manager](https://github.com/samira-sadrolashrafi/note-manager)**  
   A PHP and MySQL application using a custom MVC structure and Bootstrap. Users can create, edit, and delete notes, mark them as public or private, search and sort notes, filter by date with a Persian (Jalali) date picker, and browse paginated results. It also includes account login and a “Remember Me” feature.

4. **[SMS Panel](https://github.com/samira-sadrolashrafi/sms-panel)** · [Live Demo](https://samira-sadrolashrafi.github.io/sms-panel/)  
   A responsive Persian RTL SMS composition interface built with Tailwind CSS 4, Flowbite, and Vanilla JavaScript. It includes multiple recipient management, Iranian mobile-number validation, a message character counter, a custom Jalali calendar, and optional date/time scheduling. This is a frontend demo; it is not connected to an SMS gateway or backend.

5. **[AURA Restaurant Table Reservation](https://github.com/samira-sadrolashrafi/restaurant-table-reservation)** · [Live Demo](https://samira-sadrolashrafi.github.io/restaurant-table-reservation/)  
   A responsive Persian RTL restaurant website built with TypeScript, HTML, and CSS. Users can select multiple tables, view their capacities, simulate reservations, see reserved tables, and calculate the reservation cost. Reservation data is held in memory and resets when the page is refreshed.

6. **[Flower Shop Website](https://github.com/samira-sadrolashrafi/flower-shop-website)** · [Live Demo](https://samira-sadrolashrafi.github.io/flower-shop-website/)  
   A responsive multi-page flower shop interface built with HTML and CSS, with pages for the product catalog, product details, cart, checkout, order confirmation, profile, and contact.

7. **[Research Mate — Figma UI/UX Design](https://github.com/samira-sadrolashrafi/research-mate-ui-design)**  
   A Persian RTL desktop UI concept for an academic research platform, designed in Figma from paper sketches and digital wireframes to high-fidelity mockups and an interactive prototype.  
   [Figma Wireframes](https://www.figma.com/design/hmkzmlJYpjMhesYHVI94kl/Research_Mate_T05?node-id=129-283&t=bQ2n9ScQKqxR5EYF-1) · [High-Fidelity Mockups](https://www.figma.com/design/hmkzmlJYpjMhesYHVI94kl/Research_Mate_T05?node-id=0-1&t=bQ2n9ScQKqxR5EYF-1) · [Interactive Prototype](https://www.figma.com/proto/hmkzmlJYpjMhesYHVI94kl/Research_Mate_T05?node-id=104-9&p=f&t=lGw6WBeKwhqymyJG-1&scaling=contain&content-scaling=fixed&page-id=0%3A1)
